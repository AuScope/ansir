Data & Declarations

Data management plans and required declarations

Data Management

ANSIR requires that raw data collected using ANSIR equipment be archived in an appropriate long-term repository. This ensures data is preserved, discoverable, and available for future research.

Raw data from ANSIR equipment must be archived in the following repositories based on data type:

Data Type Repository
Seismic AusPass (via ANU)
Magnetotelluric (MT) NCI via AuScope Magnetotellurics (MT) Collection
Distributed Acoustic Sensing (DAS) NCI via AuScope Distributed Acoustic Sensing (DAS) Collection

Note: You may also retain copies of your data in your own institutional repositories.

If you have an existing FDSN network code for this or related deployments, please provide it. If you need a new network code, ANSIR can assist with registration.

To ensure data quality and discoverability, the following must be provided with your data submission:

  • Raw packed time series data - original data from the instruments
  • Higher-level data products - derived from the raw data (where applicable)
  • MT transfer functions - for magnetotelluric deployments, processed transfer functions are uploaded to the AusMT repository
  • Required metadata - including:
    • Station locations (coordinates, elevation)
    • Deployment and retrieval dates/times
    • Instrument serial numbers and sensor types
    • Sampling rates and recording parameters
    • Site conditions and installation notes
    • Data quality notes and known issues
